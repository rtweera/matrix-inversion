Matrix Inversion Calculator

Compute the inverse of a square matrix using the cofactor method.

Instructions:

  1. Enter matrix values as space-separated numbers
  2. Specify the number of rows and columns (must be equal for a square matrix)
  3. Click "Calculate Inverse" button
  4. Open browser console (F12) to see the results

Example:

  • Matrix: 1 2 3 4
  • Rows: 2
  • Columns: 2
  • Expected Inverse: [[-2, 1], [1.5, -0.5]]

Note: Open the browser console (Press F12, then go to the Console tab) to see the detailed output including matrix object, minors, adjugate, and inverse matrices.
